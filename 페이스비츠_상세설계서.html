1. 프로젝트 정의

휴대폰과 워치로 러닝 케이던스를 측정해, BPM 카탈로그에서 곡을 골라 Spotify 또는 Apple Music으로 재생하는 러닝 음악 앱.

컨셉은 "발걸음이 플레이 버튼이 됩니다"이다. 러너가 조작하지 않아도 자신의 리듬에 맞는 음악이 이어지는 경험을 제공한다.

2. 제작 범위

  • iPhone 화면 12개, Apple Watch 화면 8개의 UI 프로토타입
  • Galaxy·Galaxy Watch는 같은 화면 구조와 디자인 체계를 적용하며 전용 화면은 별도로 설계하지 않음
  • 샘플 데이터로 화면 이동을 체험하는 형태. 측정값과 곡 정보는 예시 값으로 표시
  • 기능 F1 오토 싱크, F2 케이던스 유도, F3 인터벌, F4 리듬 반응 개인화, F5 리포트·크루 챌린지의 화면 설계

3. 서비스 구성

영역구성
케이던스 측정워치 착용 시 워치 센서를, 미착용 시 휴대폰 센서를 사용. Apple은 CMPedometer, Galaxy Watch는 Wear OS Health Services STEPS_PER_MINUTE, Galaxy 휴대폰은 걸음 센서
BPM 데이터Deezer와 GetSongBPM을 교차 확인하고 수동 탭 검증을 거친 카탈로그 300곡
선곡카탈로그 안에서 BPM, Energy, 장르, 재생 이력을 점수화
재생iPhone은 Spotify Web API Player 또는 Apple MusicKit, Galaxy는 Spotify Web API Player로 재생, 다음 곡, 대기열 추가를 제어
기기 연동Apple은 WatchConnectivity, Galaxy는 Wear OS Data Layer로 휴대폰과 워치의 세션 상태를 동기화
음성·햅틱Apple은 AVSpeechSynthesizer, .duckOthers, WatchKit 햅틱. Galaxy는 TextToSpeech, Audio Focus 덕킹, Wear OS 진동
브랜드 표기곡 정보와 함께 사용 중인 음악 서비스의 로고·링크를 표시하고, 아트워크는 원형을 유지
기록 연동러닝 기록을 Apple 건강과 Health Connect로 내보내 기존 러닝 앱과 함께 사용
Galaxy 구현Kotlin, Jetpack Compose, Compose for Wear OS로 같은 화면 구조와 디자인 값을 적용

4. 페르소나·시나리오

페르소나특성핵심 니즈
정기 러너29세 직장인, 주 3회 러닝, 하프 마라톤 준비, Apple Watch 사용목표 케이던스 유지, 휴대폰을 보지 않는 인터벌 훈련
음악 중심 러너26세 대학원생, 주 2회 러닝, Spotify 또는 Apple Music 구독좋아하는 장르, 발과 맞는 박자, 기록 공유

대표 시나리오

  1. 휴대폰에서 음악 서비스를 연결하고 장르를 고른다.
  2. 휴대폰 또는 워치에서 모드를 선택해 러닝을 시작한다.
  3. 달리는 동안 앱이 케이던스에 맞춰 곡을 잇고, 사용자는 워치로 지표와 음악을 확인한다.
  4. 종료 후 워치에서 요약을 보고, 휴대폰에서 리포트를 공유한다.

7. 선곡·제어 규칙

모드목표 SPM
오토 싱크평활화된 현재 SPM
케이던스 유도직전 곡 목표 + 2~3 SPM, 사용자 목표에서 고정. 설정 범위 150~190 SPM. 러너 케이던스의 2.5% 이내 템포 변화가 효과적이었다는 연구(Van Dyck et al., 2015)를 근거로 곡당 상승폭을 제한
인터벌워밍업 165, 고강도 178, 조깅 160, 쿨다운 155 SPM
effective_bpm(track, target):
    return track.bpm 와 track.bpm × 2 중 target에 더 가까운 값

select(target, session):
    pool = |effective_bpm - target| ≤ 3 인 곡
    if pool 크기 < 5: pool = |effective_bpm - target| ≤ 5 인 곡
    return score가 가장 높은 곡

score(track):
    100 - 8 × |effective_bpm - target|
    + energy 일치 15, 인접 구간 5
    + 선택 장르 일치 10
    + 청취 기록 상위 아티스트 10
    + 곡별 리듬 유지 점수 × 0.2
    - 세션 내 재생 이력 50
이벤트동작
세션 시작첫 곡 재생, Watch 카운트다운과 진동
곡 종료 20초 전다음 곡 1개를 선정해 대기열에 추가
현재 곡과 5 SPM 이상 차이 20초 지속다음 곡 재선정
15 SPM 이상 차이 30초 지속즉시 교체, 이후 60초 동안 재교체 금지
인터벌 구간 전환3초 전 Watch 전체 화면 알림과 음성 안내, 곡 즉시 교체
100 SPM 미만 10초 지속선곡 동결, 재개 시 해제

8. 기능 명세

기능요구사항완료 기준
F1 오토 싱크케이던스에 맞춰 다음 곡 자동 선정·재생재생 시간의 70% 이상 ±3 BPM, 90% 이상 ±5 BPM
F2 케이던스 유도목표 SPM 설정, 곡 단위 +2~3 SPM 상승목표 ±3 SPM 유지 시간 비율 표시
F3 인터벌프리셋 선택, 음성 안내, 워치 햅틱, 곡 교체구간 전환 후 5초 이내 곡 교체
F4 리듬 반응 개인화온보딩 장르, 청취 기록, 곡별 리듬 유지 점수, 반복 억제선택 장르 비중 60% 이상, 러닝 5회 이후 점수 반영
F5 리포트·크루 챌린지경로, 구간 페이스, SPM, 곡 목록 이미지 공유, 크루 BPM 일치 챌린지, 건강 앱 내보내기시작·종료 200m 마스킹, 음악 서비스 표기 포함
